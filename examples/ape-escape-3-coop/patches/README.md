# PCSX2 patch files

PCSX2 can apply memory writes at boot from a plain text `.pnach` file in its
`cheats/` folder, named after the disc's CRC (`A1B2C3D4.pnach`) or its serial
(`SCUS97501.pnach`). That is the usual way a PS2 mod is distributed, and it is why
this mod can be more than a Python script: once a configuration works, it freezes
into one of these and co-op loads with the game. No watchdog, no second process.

## Generating yours

```bash
# with the game running, in a stage, on the PCSX2 the mod is talking to
aecoops export-pnach --out patches/<CRC>.pnach --p1 kei --p2 yumi
```

Get the CRC from `aecoops info`. The export reads three things out of the running
game and nothing out of this folder:

| Piece | Where it comes from |
|---|---|
| the hook site | `globals.frame_hook` in your worksheet (or `--site`) |
| the free RAM for the cave | `find_free_region` + `verify_stable`, or `--cave` |
| the baked-in entries | the same list the watchdog would write: view mode, actor count, partner flag, the two character ids, the tether |

Then copy it in:

| Platform | `cheats/` lives in |
|---|---|
| Windows | the PCSX2 install folder, or `Documents/PCSX2/cheats/` |
| Linux | `~/.config/PCSX2/cheats/` |
| macOS | `~/Library/Application Support/PCSX2/cheats/` |

Enable **Settings → Emulation → Enable Cheats**, then boot the game. The patch
list in the GUI shows it, with the comment the exporter wrote.

> **A `.pnach` is a memory patch, not a save.** Loading a savestate made *before*
> the patch was active can leave the code cave half-written, because a savestate
> restores RAM wholesale. Boot the game freshly, or reload a state made with the
> patch on.

## What is in this folder

- `EXAMPLE-SCUS-97501.pnach` -- a format reference, generated by the same builder
  that makes the real one, with made-up addresses. It shows the header lines, what
  an `extended` write looks like, how the 448-byte cave and its parameter block are
  laid out, and where the one-word trampoline lands. **It is not a working patch.**
  Its own header says so; it is here so that anyone reading a generated patch can
  see the shape without first having a working install.

Real exports are named after your disc's CRC, and they are yours: they contain
addresses measured from your own game. Nothing in this folder is game data, and
nothing here should ever become a copy of a disc.

## Making it a toggle

The exporter writes every line with the `1` flag, meaning "always apply". Change
any line to `patch=0,` and PCSX2 will show it in the patch list as something the
player can switch on and off. That is the friendliest way to ship a `.pnach` you
are still tuning: leave it off, boot, and flip it on when you are in a stage.

## Uninstalling

Delete the file. Nothing was modified on disk, and nothing outside the emulator's
own memory was ever touched.
